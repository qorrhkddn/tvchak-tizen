NAS 주소 입력

시놀로지 등에서 돌고 있는 TVChak 프록시 서버의 주소를 입력하세요.

예: http://192.168.1.230:7777

박스에 포커스 → OK 누르면 TV 키보드가 뜹니다. 입력 후 Return으로 닫고 ↓로 저장 버튼.
리모컨 가이드 TVChak v?
· 방향키 / OK: 포커스 이동·선택
· Return(복귀): 한 단계 뒤로 (카드→탭, 상세→홈, 플레이어→상세). 탭에서 누르면 플랫폼 기본 동작.
· TV 홈/Exit 키: 앱을 백그라운드로(메모리 유지) — 다시 들어오면 같은 화면.
· 숫자 1~7 (홈에서): 영화/드라마/예능/애니/검색/이어보기/즐겨찾기 바로 이동
· 숫자 1~9, 0 (상세에서): 해당 회차 바로 재생 (0 = 10화)
· 플레이어: 파랑 키 화면 맞춤 / ◀▶ 10초 시킹 / ▶⏸ 재생·정지
· 이어보기·즐겨찾기: 빨강 키 항목 삭제 / 노랑 키 ×2 전체 삭제
